Page 48 - Entity Bias 問題
範例中問題由 China 改為 America。
模型卻仍輸出 China。
展示 ICL 容易複製範例 Entity 的問題。

Page 49 - Skeleton Similarity
先將實體抽換：
China → <country>
2020 → <year>

再計算骨架句子的相似度。
避免 Entity 干擾範例選擇。

Page 51 - Refiner 機制
候選 SQL 先執行。
若失敗則交由 Refiner 修正。
最後由 Fine-tuned Ranking Model 選出最佳 SQL。
