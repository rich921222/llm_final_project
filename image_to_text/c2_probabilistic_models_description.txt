
c2_probabilistic_models 圖片詳細說明

Page 4 - Chain Rule of Probability
展示序列機率的完整展開：

p(x1,x2,...,xT)
= p(x1)p(x2|x1)p(x3|x1,x2)...

下方使用乘積符號表示。

說明語言模型的核心問題是計算整句話的聯合機率。

Page 5 - Data Sparsity Problem
沿用前頁公式。

紅字指出：

當 T 很大時，
p(xT|xT-1,...,x1)

幾乎無法估計。

展示資料稀疏問題(Data Sparsity)。

Page 6 - Markov Property
右側圖示為狀態鏈：

x(t-2)
→ x(t-1)
→ x(t)
→ x(t+1)

說明下一個狀態只依賴目前狀態。

公式：

p(x1...xT)
= p(x1)Πp(xt|xt-1)

Page 7 - Markov Assumption
中央公式：

p(xt|xt-1,xt-2,...)
= p(xt|xt-1)

下方文字：

xt independent of xt-2, xt-3...

強調 Markov 假設會忽略較久遠的歷史資訊。

Page 9 - Markov Assumption Example
兩個句子：

"I like green eggs and ham"
"I like to code in C++ and Python"

圖中箭頭指出：

ham 與 Python 不可能只依賴單字 and。

展示 Markov 假設在自然語言中的限制。

Page 10 - Markov Model
右下角為天氣轉移圖。

三個狀態：

Sunny
Cloudy
Rainy

節點間標示轉移機率。

展示 Markov Chain 的基本結構。

Page 11 - Notation
定義：

s(t) = st

表示時間 t 的狀態。

下方說明：

p(st=i)

代表在時間 t 處於狀態 i 的機率。

Page 12 - State Distribution
展示：

p(st)

為長度 M 的機率向量。

範例：

p(Sunday = Rainy)

表示星期天是雨天的機率。

Page 14 - State Transition Matrix
展示轉移矩陣公式：

Aij = p(st=j | st-1=i)

行代表上一狀態。
列代表下一狀態。

Page 15 - Time-Homogeneous Markov Process
討論：

Aij(t)

與

Aij

的差異。

說明若轉移矩陣不隨時間改變，稱為 Time-Homogeneous Markov Process。

Page 16 - Initial State Distribution
句子：

The quick brown fox jumps over the lazy dog.

紅框標示第一個單字 The。

問題：

第一個單字出現機率如何估計？

引入：

πi = p(s1=i)

Page 17 - Recap
整理 Markov Model 核心參數：

A
轉移矩陣

π
初始狀態分布

作為後續序列機率計算基礎。

Page 18 - Probability of a Sequence
推導：

p(s1...T)
= πs1 × Π Ast-1,st

綠色標籤標示：
Markov Property

展示序列機率如何由轉移機率相乘得到。

Page 19 - Training a Markov Model
利用擲硬幣例子：

p(heads)
≈ count(heads)/total

延伸到語言模型：

p(cat)
≈ count(cat)/total words

展示 Maximum Likelihood Estimation 概念。

Page 20 - Estimating A and π
展示參數估計公式：

π̂i = count(s1=i)/N

Âij = count(i→j)/count(i)

右下範例：

count("the cat") / count("the")

說明 Bigram 機率估計方式。

Page 21 - Zero Probability Problem
公式：

p(s1...T)
= πs1 × ΠAst-1,st

若某轉移從未出現：

Ast-1,st = 0

則整句機率直接變成 0。

Page 22 - Add-One Smoothing
公式：

Âij
= (count(i→j)+1)/(count(i)+M)

為 Laplace Smoothing。

右下說明：

加上 M 可確保每列機率總和仍為 1。

Page 23 - Initial State Smoothing
對 π 也套用 Add-One Smoothing：

π̂i
= (count(s1=i)+1)/(N+M)

Page 24 - Add-Epsilon Smoothing
將 +1 改成 +ε。

ε > 1
更平滑

ε < 1
較少平滑

可控制平滑強度。

Page 25 - Underflow Problem
說明：

許多小機率相乘後接近 0。

電腦浮點數可能直接下溢為 0。

引出 Log Probability。

Page 26~27 - Log Probabilities
利用：

log(AB)
= log(A)+log(B)

將乘法轉成加法。

避免 Underflow。

Likelihood
Prior

並利用 Bayes Rule 轉換。

Likelihood

Page 53 - Pros & Cons of Markov Models
優點：
- 簡單
- 易解釋
- 適合序列資料

缺點：
- 缺乏長期記憶
- 無法處理語意歧義
- 效果落後 Transformer
