Page 2 - What is Topic Modeling
介紹 Topic Modeling 的基本概念。

重點：
- Unsupervised Learning
- 不需要人工標籤
- 自動從大量文件中發現隱藏主題

與 Classification 不同，
Topic 並非事先定義，而是由資料自行產生。

Page 3 - Latent Dirichlet Allocation (LDA)
介紹最常見的 Topic Modeling 方法。

核心概念：
Document = Topic Mixture
Topic = Word Distribution

例如：
論文可能同時包含
60% AI
40% Statistics

Page 4 - Non-Negative Matrix Factorization (NMF)
介紹 NMF。

利用 Matrix Factorization：

Document-Term Matrix
↓
W × H

找出隱藏主題。

適合：
- Sparse Matrix
- 短文本
- TF-IDF 特徵

Page 5 - Latent Semantic Analysis (LSA)
介紹 LSA。

核心技術：

Singular Value Decomposition (SVD)

利用降維發現文件與詞彙間潛在語意關係。

Page 6 - LDA Overview
整理 LDA 特性：

- Probabilistic Generative Model
- Dirichlet Prior

- 需預先指定 Topic 數量 K

Page 20 - Gibbs Sampling Formula
展示完整條件機率公式。

P(zi=k|wi,d)

涉及：

n(d,k)
n(k,w)
α
β

為 LDA 最核心數學公式。

Page 21 - Gibbs Sampling Intuition
將公式翻譯成人話：

P(標籤=網美 | 其他人的狀態)

說明 Gibbs Sampling 本質是重新估計標籤機率。

Page 22 - Alpha Interpretation
公式中的：

n(d,k)+α

被解釋為：

「該地區目前的網美比例 + α」

表示文件中的 Topic 比例。

Page 23 - Beta Interpretation
公式中的：

n(k,w)+β

被解釋為：

「全台北靜香被歸類為網美的次數 + β」

表示 Topic 對 Word 的偏好程度。
