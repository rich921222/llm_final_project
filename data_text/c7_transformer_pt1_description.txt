Page 2 - Transformer 發展時間線
展示 Transformer 家族的重要模型演進：
Transformer(2017) → GPT → BERT → GPT-2 → RoBERTa → ALBERT → GPT-3 → GPT-4。
強調 Transformer 成為現代 NLP 基礎架構。

Page 6 - Attention Mechanism 直觀概念
使用台灣降雨熱度圖作為例子。
紅框圈出最醒目的高降雨區域。
說明人類觀看圖片時會優先關注重要區域，這就是 Attention 的概念。

Page 7 - 人類記憶模型與 Attention
將 Attention 類比為人類認知系統：
Sensory Memory → Attention → Working Memory。
大量資訊先進入感官記憶，再透過注意力篩選重要資訊。

Page 9 - Seq2Seq Machine Translation
左圖展示 Encoder-Decoder 架構。
Encoder 將輸入句子壓縮成 Hidden State。
Decoder 根據 Hidden State 逐步生成翻譯結果。

Page 10 - Machine Translation without Attention
RNN Encoder 將整句資訊壓縮到最後一個 Hidden State。
Decoder 僅依靠單一向量進行翻譯。
此架構容易遺失長句資訊。

Page 15~16 - Query / Key / Value
以翻譯系統解釋 Attention。
Query 代表目前需求。
Key 代表各輸入特徵。
Value 代表實際內容。
最終透過加權平均得到 Context Vector。

Page 18~22 - Attention 計算流程
展示：
1. Query 與 Key 計算相似度
2. Softmax 轉為權重
3. 權重乘上 Value
4. 加總形成 Context Vector
5. Decoder 逐步產生 machine、translation 等輸出

Page 25 - Self-Attention
句子 "The cat sat"。
建立 token 表示時，每個 token 同時參考自己與其他 token。
例如 cat 會觀察 The 與 sat。

Page 26~28 - Multi-Head Attention
展示多頭注意力概念。
不同 Head 學習不同語言關係：
主詞動詞關係、介系詞結構、修飾語關係等。
最後融合所有 Head 的結果。

Page 31 - BERT 基本架構
文字輸入先轉換為 Word Embedding。
經過 BERT Encoder 後產生 Contextual Representation。
說明 BERT 能利用上下文理解詞意。

Page 36 - BERT 訓練流程
左側為 Pre-training。
包含：
- Masked Language Modeling (MLM)
- Next Sentence Prediction (NSP)

右側為 Fine-tuning。
展示問答、NER、分類等任務如何接上 BERT。

- 12 Encoder Layers
- 12 Attention Heads
- 110M Parameters

- 24 Encoder Layers
